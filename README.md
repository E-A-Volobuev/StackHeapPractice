📦 Практика Stack vs Heap.

📋 Данный проект позволяет наглядно понять разницу работы со стеком и кучей.
В проекте приведены тесты производительности, включая замеры времени и потребляемой памяти.

🚀 Возможности
1) Простое сравнение стека и кучи для 10_000_000 операций. Вывод результата в консоль.
2) Сравнение потребляемых ресурсов с помощью Benchmark.

📋 Требования
.NET 8.0 или выше

Для простого сравнения стека и кучи в файле Program.cs неотходимо закомментировать строку:
--> BenchmarkRunner.Run<CounterTest>();

Для сравнения потребляемых ресурсов с помощью Benchmark в файле Program.cs комментируем весь код, кроме строки:
--> BenchmarkRunner.Run<CounterTest>();
